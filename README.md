# 🏥 약알고 (YAK_AL_GO)

의약품 정보를 빠르고 정확하게 검색하고,
안전한 복용을 위한 
DUR 정보 / 약국 위치정보 / 자유, 전문가 Q&A를 제공하는 

웹 기반 의약품 정보 플랫폼입니다.

개발 기간 : 2025/05/07 ~ 2025/06/05

<hr/>

- **서비스 URL** : 🌐 [약알고 바로가기](https://yakalgo.kr)


### 📌 프로젝트 개요

프로젝트 명: 약알고 (YAK_AL_GO)

목적: 의약품 정보 검색 및 안전한 복용을 위한 DUR(Drug Utilization Review) 정보 제공

대상 사용자: 의약품 정보가 필요한 일반 사용자, 의약품 관리가 필요한 약사 사용자

<hr/>

### 🌟 핵심 가치
2만개 의약품 데이터 기반 빠르고 정확한 검색 기능

5천개의 약국 데이터 정보 제공

개인 맞춤형 복용약 관리 및 약사 한정 재고 관리 시스템

직관적인 UI/UX로 누구나 쉽게 사용 가능한 서비스

## 🚀 프로젝트 특징

### ✨ 차별화 포인트
공공데이터 활용: 식약처 의약품 및 약국 허가정보 2만 5천건 데이터 활용

실용성 중심: 일반 사용자와 약사 모두를 위한 이중 서비스

안전성 우선: DUR 시스템으로 안전한 약물 복용 지원

접근성: 일반 사용자 및 약사 모두 사용 가능한 커뮤니티

### 🎯 기대 효과
의약품 정보 접근성 향상으로 국민 건강 증진

약물 오남용 방지 및 안전한 복용 문화 조성

약국-환자 간 정보 격차 해소

개인 맞춤형 약물 관리로 복약 순응도 향상

📝 약알고 프로젝트 피드백 요약 정리
 
0. AI 기능 및 피드백 반영
AI 기반 기능 도입 및 사용자 피드백 적극 반영 필요

1. 약국 범위 확대
서비스 지역을 경기도권 등으로 확장

2. 약품명 표기 오류
아모닐정 등 괄호·특수문자 포함 약품명 표기 오류 수정

3. 검색 기능 고도화
약 검색 시 관련 병명, 카테고리 등 다양한 조건으로 검색 가능하게 개선

4. 약사 회원 정보 입력 최소화
약사 회원가입 시 건강상태·질병 정보 입력 필요성 재검토

5. 사용자 프라이버시 강화
닉네임(예: 김OO) 등 익명성 강화 또는 질문 비공개 옵션 제공

6. 약사 커뮤니티 및 로그인 개선
- 약국명 노출, 로그인 시 약국 정보 표시
- 약사 회원은 카카오 로그인 대신 로컬(이메일/비밀번호) 로그인 지원

7. 회원가입 시 질병 정보 입력 및 재활용
기타(직접입력) 항목 추가 및 입력 데이터 서비스 내 재활용

8. 건강상태 입력 다양화
임산부, 노인, 소아, 시한부 등 다양한 건강상태 선택 가능하게

9. 회원가입 단계 UI 개선
1단계/2단계 구분이 혼란스러움 → 단계별 안내 및 UX 개선

10. 24시간 당직 약사 대기(AI 약사) 기능
AI 활용 24시간 약사 상담 기능 도입 및 유료화 방안 검토

11. 의약품 데이터 보완
약학정보원에는 있으나 서비스에는 없는 약(예: 노즈그린) 데이터 보완

12. 서버 라우팅 및 페이지 접근 오류
내부 경로 직접 접근 시 "URL is not safe to open" 등 에러 발생
딥링크, SEO, 공유·재방문성 저하 문제

13. 메인페이지 유저 수 표시
user 수를 계산해 메인페이지에 실시간 반영

14. 법적·정보 제공 페이지 미비
이용약관, 개인정보처리방침, 회사 정보 등 필수 법적 안내 페이지 및 링크 추가 필요

15. SPA 구조 및 직접 접근 문제
서버 리다이렉트 미설정으로 직접 URL 접근 시 404/접근 에러
검색 등 주요 기능도 직접 URL 호출 불가 → UX 저해
